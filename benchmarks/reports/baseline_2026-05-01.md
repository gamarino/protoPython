## Attribution

The dominant contribution is the attribute-cache work in protoCore:
- `c5a6fb9a` — Tier A1: inline isObject + pointer-hashed attribute cache key
- `982db143` — Optimize attribute cache hash shift (>> 6)
- `e706c2d8` — adopt OS main thread so attribute cache is reachable from rootContext
- `6eb3f1e4` — auto-detect main OS thread in ProtoContext for cache inheritance
- `af1cfbea` — route setAttribute / addParentInternal CAS reads through mutable cache

`attr_lookup` improving 2.75× and `richards_lite` improving 19% both align with attribute-cache effectiveness. The minor regressions on `int_sum_loop` and `call_recursion` are within single-run noise on the 5-iteration median.
